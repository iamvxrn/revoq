## Building Your First Project

### 1. Initialize a C++ Project

Create a new binary project:

```bash
mkdir my-cpp-app && cd my-cpp-app
revoq init
```

### 2. Build and Run

Compile translation units and execute the binary:

```bash
revoq build
revoq run
```
