## Installation Methods

### Via Cargo (Crates.io)

Revoq is published directly on Crates.io:

```bash
cargo install revoq
```

### Via Lown

Install using Lown's short alias:

```bash
lown install revoq
```

### Shell Installer

```bash
curl -fsSL https://revoq.pages.dev/install.sh | sh
```
