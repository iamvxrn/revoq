System Architecture

Build System Specifications

01
Strict Project Layout
Entry points are deterministic: src/main.cpp / src/main.c for binaries or src/lib.cpp / src/lib.c for libraries. Unresolved entries halt compilation.
02
Reproducible Dependency Graph
revoq.lock pins dependencies to exact Git commit SHAs via atomic file swaps. revoq build strictly honors locked states.
03
Parallel Work Queue
A multi-threaded worker queue compiles translation units in parallel across available CPU cores, streaming diagnostic outputs as units finish.
