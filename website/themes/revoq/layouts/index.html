Designed for modern C/C++ workflows

Zero CMake Boilerplate

Put your entry point in src/main.cpp or src/lib.cpp and run revoq build. No build scripts, no complex Makefile rules.

Deterministic Lockfile

revoq.lock pins exact Git commit SHAs across all dependencies for bit-for-bit reproducible builds.

Parallel Clang Engine

Multi-threaded worker pool compiles C/C++ translation units in parallel across CPU cores.

Offline Vendoring

revoq vendor freezes all third-party dependencies into third_party/ for offline compilation.
